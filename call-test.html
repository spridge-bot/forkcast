What this tests, and what it doesn't. This checks your camera, microphone, lighting and how well this computer encodes HD video (for example whether the processor keeps up), which is what decides how you look and sound. The call runs inside this computer, so it doesn't test the trip across the internet. For that, run Webex's official test meeting (link above) while netwatch watches the line. Webex in Citrix runs the camera through the Webex VDI plugin on the iMac, so test on the iMac itself.
